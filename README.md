# Groundwater Level Forecasting Using Statistical and Machine Learning Models

## Project Overview
This project focuses on spatiotemporal groundwater level forecasting in a climate-sensitive coastal aquifer in Bangladesh using statistical and machine learning approaches.

## Research Objectives
- Analyze historical groundwater level fluctuations.
- Investigate the influence of climatic and environmental variables on groundwater dynamics.
- Develop and compare statistical and machine learning models for groundwater level forecasting.
- Evaluate spatial variations in groundwater vulnerability.

## Models Implemented
- SARIMA
- Long Short-Term Memory (LSTM)
- Random Forest (RF)
- Extreme Gradient Boosting (XGBoost)

## Model Evaluation
Model performance is evaluated using:
- Root Mean Square Error (RMSE)
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Coefficient of Determination (R²)
- Nash–Sutcliffe Efficiency (NSE)
- Mean Absolute Percentage Error (MAPE)
